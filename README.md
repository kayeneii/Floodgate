# 🌍 Project Floodgate: Mapping Flood Risk Zones Using Open Data

An open-source flood-risk analysis project for Nigeria.  
Built entirely in the cloud using Google Earth Engine, Google Colab, and OpenStreetMap data.

## Goals
- Collect and visualize open flood-related geospatial datasets.
- Develop a scalable risk index for flood vulnerability assessment.
- Demonstrate browser-based geospatial workflows for analysts in low-resource settings.

## Tech Stack
- Google Earth Engine
- Google Colab (GeoPandas, Folium, Rasterio)
- Overpass Turbo (OpenStreetMap)
- GitHub for version control

## Outputs
- DEM and rainfall layers (GeoTIFF)
- Roads, hospitals, buildings (GeoJSON)
- Flood Exposure Index (CSV + map)
